## [Phase 0] — Scaffolding & Setup — COMPLETED 2026-07-28

**What was built:**
- Scaffolded Next.js 14 project using App Router, TypeScript, and Tailwind CSS.
- Initialized shadcn/ui and fixed related CSS/Tailwind configuration to be compatible.

- Applied Prisma schema (User, Package, Quotation, QuotationItem).
- Set up route groups (`app/(admin)`, `app/(agent)`, `app/(auth)`).

- Resolved shadcn CSS overriding and missing animate plugin issues manually to ensure a clean production build.
